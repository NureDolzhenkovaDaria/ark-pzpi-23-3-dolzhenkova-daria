3 ОПИС ВИКОНАНОЇ РОБОТИ

3.1. Бізнес-логіка серверної частини та математична обробка даних
Окрім стандартних CRUD-операцій, серверна частина системи «EmoAd» реалізує бізнес-логіку статистичного аналізу. Зокрема, додано математичний метод розрахунку конверсії та популярності рекламних банерів на основі таблиці analytics_logs та feedback:
    Аналіз розподілу емоцій: сервер обчислює відсоткове співвідношення натискань кожної емоції від загальної кількості запитів для оцінки поведінки користувачів.
    Розрахунок середнього рейтингу: на основі таблиці feedback обчислюється середньоарифметична оцінка ефективності конкретного рекламного банера.

3.2 Функції адміністрування
Адміністративний модуль розширено новими можливостями контролю системи:
    Управління користувачами та блокування: адміністратор може змінити статус користувача (is_blocked = 1), що забороняє йому доступ до кабінету.
    Експорт аналітичних даних (Backup / Export): реалізовано можливість вивантаження всієї зібраної статистики у зручному структурованому JSON-форматі для резервного копіювання.

Програмний код

В.1 Бізнес-логіка статистичного аналізу даних та розрахунок рейтингів
1  @router.get("/admin/analytics/summary")
 2  async def get_analytics_summary(db: Session = Depends(get_db)):
 3      logs = db.query(AnalyticsLogDB).all()
 4      total_clicks = len(logs)
 5      if total_clicks == 0:
 6          return {"total_interactions": 0, "emotion_distribution": {}}
 7      
 8      emotion_counts = {}
 9      for log in logs:
10          emo = log.selected_emotion
11          emotion_counts[emo] = emotion_counts.get(emo, 0) + 1
12          
13      distribution = {
14          emo: {"count": count, "percentage": round((count / total_clicks) * 100, 2)}
15          for emo, count in emotion_counts.items()
16      }
17      return {"total_interactions": total_clicks, "emotion_distribution": distribution}

14          }
